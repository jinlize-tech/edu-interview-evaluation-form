# 面试评价表专业工作手册

## 任务目标

面试评价表。

## 任务专属判断规则

- 所有结论必须回指用户提供的岗位能力模型、面试记录、评分维度和招聘决策规则，不得以模型常识替代未提供的业务事实。
- 核心失败条件：凭主观印象评分或把建议当最终录用决定。
- 去重边界：与面试题库区别：用于面试后评价和证据汇总，不重复出题。
- 交付「评价表字段」时必须给出结果、依据、执行责任或下一步、完成标准，不能只给原则性建议。
- 交付「行为锚点评分」时必须给出结果、依据、执行责任或下一步、完成标准，不能只给原则性建议。
- 交付「综合结论」时必须给出结果、依据、执行责任或下一步、完成标准，不能只给原则性建议。
- 交付「证据缺口和决策建议」时必须给出结果、依据、执行责任或下一步、完成标准，不能只给原则性建议。
- 首次响应只询问最多3个会实质改变结论的缺失信息；可安全继续时先声明假设并产出有限草案。
- 用户目标变化时，保留已确认内容，重述受影响成果，并只重新询问必要字段。

## 输入证据矩阵

| 输入项 | 必须核验 | 不满足时的处理 |
|---|---|---|
| 岗位能力模型 | 来源、时间、对象范围、统计单位、责任人、是否已确认 | 列为待确认；不得补造；限制受影响结论 |
| 面试记录 | 来源、时间、对象范围、统计单位、责任人、是否已确认 | 列为待确认；不得补造；限制受影响结论 |
| 评分维度和招聘决策规则 | 来源、时间、对象范围、统计单位、责任人、是否已确认 | 列为待确认；不得补造；限制受影响结论 |

| 成果 | 最低要求 | 通过条件 |
|---|---|---|
| 评价表字段 | 结构化结果、输入依据、可执行动作、风险 | 无空泛表述；关键字段可追溯；用户可直接进入下一步 |
| 行为锚点评分 | 结构化结果、输入依据、可执行动作、风险 | 无空泛表述；关键字段可追溯；用户可直接进入下一步 |
| 综合结论 | 结构化结果、输入依据、可执行动作、风险 | 无空泛表述；关键字段可追溯；用户可直接进入下一步 |
| 证据缺口和决策建议 | 结构化结果、输入依据、可执行动作、风险 | 无空泛表述；关键字段可追溯；用户可直接进入下一步 |

## 专业检查

- 从岗位任务、汇报关系、任职资格、协作接口和绩效证据出发，不针对个人画像。
- 区分必要条件与可培养条件，避免歧视性、无限扩张或不相关限制。
- 涉及劳动关系、纪律、薪酬和合规结论时要求专业人员复核。
- 招聘、培训、绩效和入职材料应保留责任人、时间与确认节点。

本手册是任务规则参考，不是外部事实来源；涉及政策、法律、财税、劳动用工或教育标准时必须核验地区、有效期和官方来源。
